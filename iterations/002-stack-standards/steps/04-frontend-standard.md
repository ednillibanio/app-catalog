# Stage 04: frontend standard

Status: `todo`

## Objective and scope

Write a frontend standard in `docs/standards/` with its `.pt-BR.md` (file name decided at stage start, in the style of stage 03), a shared standard for React/Vite/TypeScript applications in a pnpm and Turborepo monorepo, rewritten from the generic parts of the maintainer's existing frontend standard. Index it in the standards README and record the source in `PROVENANCE.md` as in stage 03. Tracked in [#13](https://github.com/ednillibanio/app-catalog/issues/13). Detailed at stage start.

## Out of scope

Application-specific rules (application names, ports, domain packages) and any change in the application repository.

## Acceptance criteria and validation

As in stage 03: no application-specific name or data in the standard. At stage start, check the git history of the source file: material adapted from organization sources is not copied (`PROVENANCE.md`); it is rewritten from the implementation or left out.

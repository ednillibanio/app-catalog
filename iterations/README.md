The [stack standards](002-stack-standards/README.md) iteration makes this repository the independent source of truth for the standards shared by application repositories on one stack and keeps reader-facing docs in English and Portuguese. Its master issue is [#16](https://github.com/ednillibanio/app-catalog/issues/16).

Iteration 001 founded this repository under master issue [#1](https://github.com/ednillibanio/app-catalog/issues/1). Its records described one application's adoption, so they were removed in iteration 002 (decision D6) and remain in the Git history.

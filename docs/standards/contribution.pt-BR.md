# Fluxo de contribuição

Registre o trabalho aceito numa issue no repositório que é dono dele. Em trabalho entre repositórios, ligue a issue de cada repositório à issue mãe. Crie as branches de tópico a partir da branch de integração do repositório; este catálogo usa a `main`. Use Conventional Commits em inglês e pull requests para a branch de integração. Descreva a mudança, a validação, a revisão e os riscos restantes. O mantenedor aprova commits, pushes, pull requests e merges separadamente. Siga as regras locais mais estritas do repositório que recebe a mudança. Não faça push direto numa branch protegida nem altere proteções sem aprovação separada.

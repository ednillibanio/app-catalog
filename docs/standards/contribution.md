# Contribution workflow

Record accepted work in an issue in the repository that owns it. For cross-repository work link each repository's issue to the master issue. Start topic branches from the repository's integration branch; this catalog uses `main`. Use Conventional Commits in English and pull requests targeting the integration branch. Describe the change, validation, review and remaining risks. The maintainer approves commits, pushes, pull requests and merges separately. Follow the receiving repository's stricter local rules. Do not push directly to a protected branch or change protections without separate approval.

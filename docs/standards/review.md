# Review

Review plans before approval, completed stages before closure, changes before push or pull request, and changes before an authorized merge. Check scope, correctness, risks, documentation and evidence. Record reviewer, findings, disposition and result in the stage or pull request. Review does not authorize an action.

The catalog does not install or mandate a particular review tool. Each repository documents its own reviewers and any stricter requirements; for example, a repository may require a documentation audit and an independent automated review at each of its review points. A failed or unavailable review is not an approval; report it and resolve the cause before claiming it completed. Follow tool and repository rules for independent review and retained records.

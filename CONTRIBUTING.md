# Contributing

Read the [contribution workflow](docs/standards/contribution.md), [iteration workflow](docs/standards/iterations.md) and [review standard](docs/standards/review.md). Work from `main` in a topic branch associated with an issue; use a separate issue and pull request for work in each repository. Obtain the approvals described there and in local instructions before each action. Reader-facing documents have an English file and a `.pt-BR.md` translation; change both in the same pull request, as the [documentation standard](docs/standards/documentation.md#languages) describes. Validate links, examples, language pairs and structured data before requesting review.

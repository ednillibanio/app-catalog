# Como contribuir

Leia o [fluxo de contribuição](docs/standards/contribution.pt-BR.md), o [fluxo de iterações](docs/standards/iterations.pt-BR.md) e o [padrão de revisão](docs/standards/review.pt-BR.md). Trabalhe a partir da `main`, numa branch de tópico associada a uma issue; use uma issue e um pull request separados para o trabalho em cada repositório. Obtenha as aprovações descritas nesses documentos e nas instruções locais antes de cada ação. Os documentos para leitores têm um arquivo em inglês e uma tradução `.pt-BR.md`; altere os dois no mesmo pull request, como descreve o [padrão de documentação](docs/standards/documentation.pt-BR.md#idiomas). Valide links, exemplos, pares de idioma e dados estruturados antes de pedir revisão.

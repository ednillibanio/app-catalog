# Agent instructions

Read [README.md](README.md), [standards](docs/standards/README.md), the relevant iteration and its stage before changing files. Reader-facing documentation exists in English and Brazilian Portuguese: update both versions in the same change, following the language rules in the [documentation standard](docs/standards/documentation.md#languages). Use English in agent instructions, provenance, iteration records, issues, pull requests, commits and automation text; preserve product text and domain identifiers in their existing language.

Work within the approved stage. Confirm with the maintainer before starting a stage, committing, pushing, opening or merging a pull request, posting on an issue, publishing a release or changing repository settings. A confirmation for one action does not authorize the next. More restrictive repository-local rules apply to that repository.

Use a branch and a linked issue for each repository's work. Review and validate the actual changes and record evidence and limitations. Do not claim that a planned integration or an untested platform works. Never include secrets or internal organization data in this public catalog.
